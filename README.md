# Умный кампус AI (Smart Campus AI)

Учебный прототип интеллектуальной веб-платформы управления инфраструктурой учебного заведения: аудитории, IoT-датчики, энергопотребление, заявки на ремонт и модуль AI-аналитики для поиска аномалий.

**Автор:** Эсенканов Н.А., группа КС-1-24
**Проверил:** Каныбеков К.К.

## Возможности

| Страница | Что умеет |
|---|---|
| Вход (`index.html`) | Учебная имитация входа, роли: Администратор, Инженер, Оператор |
| Панель управления (`dashboard.html`) | 6 KPI-карточек, 4 графика Chart.js, уведомления, проблемные помещения |
| Помещения (`rooms.html`) | 14 помещений, поиск, фильтр по корпусу и статусу (Норма / Внимание / Критично) |
| Устройства (`devices.html`) | 24 IoT-устройства, поиск, фильтр по типу и состоянию, включение/отключение |
| Заявки (`incidents.html`) | CRUD: добавление, изменение, удаление с подтверждением |
| Аналитика (`analytics.html`) | Аномалии по порогам и z-score, уровень риска, рекомендации, создание заявки из аномалии |
| Настройки (`settings.html`) | Тёмная/светлая тема, название кампуса, автообновление, сброс тестовых данных |

Все данные хранятся в `localStorage` браузера, поэтому после перезагрузки страницы изменения сохраняются.

## AI-аналитика

1. **Пороги:** температура ≥ 28 °C — «Внимание», ≥ 32 °C — «Критично»; CO2 ≥ 1000 / 1500 ppm; энергия +30% / +60% от базовой линии помещения.
2. **Z-score:** `z = |x − μ| / σ` по последним 12 замерам. При `z > 2` значение считается статистической аномалией.
3. **Рекомендации:** правила (rule-based) выдают совет оператору для каждой аномалии.

Это статистический анализ, а не генеративный AI: внешние платные API и секретные ключи не используются.

## Запуск

Откройте ссылку GitHub Pages или запустите локальный сервер в папке проекта:

```
python3 -m http.server 8000
```

и перейдите на `http://localhost:8000`.

## Технологии

HTML5, CSS3 (Grid, Flexbox, адаптивность 1920 / 1366 / 768 / 390 px), JavaScript, localStorage, Chart.js 4.4.1, Git, GitHub Pages.
